Halo! 👋

Nama saya Sofia Ayu Lestari. Saya merupakan mahasiswa Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro.

Saya memiliki ketertarikan mendalam pada bidang pengembangan web, front-end, UI/UX, pemrograman, dan analisis sistem informasi. Saya sangat senang mempelajari teknologi baru dan mencoba menerapkannya secara langsung melalui berbagai tugas maupun proyek perkuliahan.

Bagi saya, teknologi bukan hanya tentang membuat sebuah sistem dapat berjalan, tetapi juga bagaimana sistem tersebut mampu memberikan pengalaman pengguna yang intuitif, nyaman, dan mudah dipahami.

Website ini dibuat sebagai bagian dari latihan mata kuliah Pemrograman Web untuk menerapkan berbagai elemen HTML5 secara terstruktur dan semantik.
